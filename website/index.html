Bring your own models and tools. OpenArva helps turn a request into a plan, carries out approved steps, and gives you a clear result.

Bounded autonomy

From “can you help?” to work you can verify.

OpenArva structures autonomous tasks as a controlled workflow—not a black box. It plans with available tools, asks before consequential actions, and keeps a record so you can inspect what happened.

Up and running in minutes

Make OpenArva yours.

Install the CLI, launch the setup wizard, and pick a provider. To use cloud models, set the matching API key in your environment. For local inference, connect Ollama or LM Studio.

# Install OpenArva
npm install -g openarva

# Configure your agent
openarva init

# Start with a task
openarva run --domain coding --instruction "Explain this project"

Good to know

Questions, answered.

What is OpenArva?

OpenArva is a personal AI agent you can run from your computer. It brings supported AI providers, local memory, workspace tools, and optional messaging connectors together behind permission and approval controls.

Do I have to use a cloud AI provider?

No. OpenArva supports local model endpoints such as Ollama and LM Studio. Enable local-only mode to block cloud routing; local inference still requires an available local model that can perform the requested task.

Does OpenArva connect to every platform in its catalog?

No. The catalog includes many scaffolds and interface placeholders. Working integrations are identified separately in the project capability matrix; a catalog listing alone does not mean a service adapter is implemented.

Where does OpenArva store memory?

Local vector memory is stored in SQLite in your home directory under ~/.openarva/memory/. You can index local documents and clear the stored memory with the CLI.

Is OpenArva fully autonomous?

OpenArva can plan and execute bounded tasks using registered tools, but it is not AGI or ASI. Tool permissions, approvals, timeouts, and verification limit what it can do, and you remain responsible for reviewing consequential changes.

What do I need to get started?

Use a supported Node.js version and npm, install the CLI, and run openarva init. Configure either a supported provider credential or a reachable local model endpoint. See the README for detailed setup guidance.
